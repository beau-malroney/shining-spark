# shining-spark
Ollama Private Chat bot
## Set up Backend
`pip install langchain langchain-community python-dotenv`

## Run Backend
`python back-end/ollama_chat.py`

## Set up Frontend
`cd shining-spark/front-end/ollama-chat-ui`

## Run Frontend
`npm start`

## Start Ollama
`ollama run gemma3`

## Standalone
`pip install streamlit`
`pip install pyttsx3`
`pip install ollama`

`pip install reqs.txt`

`streamlit run ./streamlit_app.py`
